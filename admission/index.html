2

진단평가

전국 단위 표본 기반의 4개 영역 진단평가를 진행합니다. 아이의 현재 위치를 객관적 데이터로 파악합니다.

3

수업 설계

진단 결과를 바탕으로 원장이 직접 최적의 반 배정과 학습 로드맵을 상담을 통해 제안합니다.

진단평가 안내

전국 단위 표본 기반
4개 영역 정밀 분석

단순한 레벨 테스트가 아닙니다. 전국 단위 표본을 활용해 아이의 현재 위치를 정확히 파악하고, 4개 영역별로 강점과 약점을 분석합니다.

분석 결과를 바탕으로 원장이 직접 학습 방향과 수업 방식을 제안합니다. 진단평가 비용은 학원이 부담합니다.

반 배정 기준

Individual Program

1:1 개별 맞춤 진도반

초등 전 학년 · 중등 1학년 권장

Hybrid Program

하이브리드 전략반

중등 2학년 이상 · 진도 적합성 확인 후 배정

학습량과 난이도가 급상승하는 시기입니다. 하이브리드반은 수업 진도가 맞아야 합니다. 진단평가 결과와 원장 상담 후 배정이 결정됩니다.

반 배정은 학년이 아닌 아이의 현재 상태를 기준으로 합니다.
진단평가 결과에 따라 조정될 수 있습니다.

학습 포인트 제도

규율이 아닌
심리적 안전벨트입니다

명확한 기준은 아이에게 예측 가능한 환경을 만들어줍니다. "이렇게 하면 어떤 결과가 온다"는 것을 알 때 아이는 눈치 보는 대신 학습에 집중할 수 있습니다.

포인트는 감정이 없는 데이터입니다. 선생님의 기분이 아닌 행동의 결과로 아이가 스스로를 관리하는 힘을 기릅니다.
